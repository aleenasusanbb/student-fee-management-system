# Student Fee Management System

A web-based Student Fee Management System developed as an IT portfolio project.

## Project Overview

The Student Fee Management System is designed to manage student information and fee-related details through a simple web interface.

The project was also tested using manual functional testing to verify that the main features work as expected.

## Features

* Student information management
* Fee information management
* Student details entry
* Fee details entry
* Basic form validation
* Simple and user-friendly interface

## Testing

Manual functional testing was performed on the application.

### Testing Activities
